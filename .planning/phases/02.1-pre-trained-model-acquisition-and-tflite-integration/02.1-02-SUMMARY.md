## Decisions Made
- **BINARY_INPUT_SIZE=192 (not 224):** Plan text referenced 224x224, but Plan 01 discovered AIY Food V1 actually takes 192x192 input. Used actual model dimensions.
- **2024 classes (not 2023):** Same discovery -- the model has 2024 output classes, not 2023. Updated all constants and tests accordingly.
- **Manual loop for binary gate max:** Used `for` loop instead of `Math.max(...spread)` to avoid potential stack overflow on 2024-element array.
- **Food-only post-filter in DetectionScreen:** Added optional post-filter using COCO_FOOD_CLASS_IDS to hide non-food COCO detections. Debug logging under `__DEV__` flag for observability.
- **tfliteAsset.js mock:** Created a Jest moduleNameMapper that maps .tflite require() calls to a mock returning numeric 1, simulating Metro bundler's asset ID resolution.
