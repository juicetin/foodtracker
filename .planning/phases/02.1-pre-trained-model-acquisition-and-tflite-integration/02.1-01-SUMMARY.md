## Decisions Made
- **AIY model actual dimensions:** The real model uses 192x192 uint8 quantized input (not 224x224 as documented in research). Output is [1, 2024] (not [1, 2023]). Quantization: scale=0.0078125, zero_point=128. This means imagePreprocess.ts needs to resize to 192x192 (not 224x224) and provide uint8 [0-255] pixels (not float32). The existing float32 [0,1] normalization will NOT work -- requires adaptation in Plan 02 or 03.
- **YOLO11n instead of YOLO26n:** YOLO26n export to TFLite fails with an onnx2tf TopK scalar conversion error. The YOLO_FALLBACKS pattern was designed for this exact scenario. YOLO11n exports cleanly with confirmed [1, 84, 8400] output shape. Both models share the same detection pipeline interface.
- **Kaggle API replaces GCS:** The original GCS download URL (storage.googleapis.com/tfhub-lite-models/) returns 403 Forbidden. Google migrated TFHub models to Kaggle. The Kaggle Models API works without authentication and returns a tar.gz archive.
- **ai-edge-litert over tflite-runtime:** Neither tflite-runtime nor tensorflow installs on Python 3.12+. Google's newer ai-edge-litert (v2.1.2) provides the same Interpreter API and works on Python 3.12.
- **English label extraction:** The model embeds both Freebase MID labels (probability-labels.txt) and human-readable English names (probability-labels-en.txt). The script prefers the English file.
