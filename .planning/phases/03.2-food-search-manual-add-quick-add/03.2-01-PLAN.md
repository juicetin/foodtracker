  <behavior>
    - getRecentHistory(limit=20) returns HistoryItem[] with {name, totalCount, lastLogged, avgCalories, avgProtein, avgCarbs, avgFat} sorted by totalCount DESC then lastLogged DESC
    - searchHistory(query, limit=10) filters history items where name LIKE %query% (case-insensitive)
    - History items come from two sources: scanned_dishes.name (camera entries) UNION food_entries.notes (manual entries where no scanned_dishes exist)
    - Manual entries with notes starting with "Copied:" or "Quick Add:" are parsed to extract clean food name
    - Entries with is_deleted=1 are excluded
    - validateMacros(cal, protein, carbs, fat) returns {isValid, expected} where expected = protein*4 + carbs*4 + fat*9, isValid = |cal - expected| <= max(expected*0.1, 20)
    - validateMacros returns isValid=true when all fields are 0 (empty form state)
    - validateMacros returns isValid=true when only some macros are filled (tolerance handles partial entry)
  </behavior>
  <action>
    Create historyService.ts with two exported functions:

    1. `getRecentHistory(limit = 20): HistoryItem[]` — synchronous function using opsqlite.execute() with raw SQL:
       - Query scanned_dishes JOIN food_entries (WHERE is_deleted=0) grouped by sd.name, with COUNT(*) as count, MAX(fe.created_at) as last_logged, and AVG of per-dish macros (entry macros / dish count per entry)
       - UNION ALL with food_entries WHERE is_deleted=0 AND notes IS NOT NULL AND id NOT IN (SELECT entry_id FROM scanned_dishes) — grouped by notes
       - Outer query: GROUP BY name, ORDER BY total_count DESC, last_logged DESC, LIMIT ?
       - Parse notes for manual entries: strip "Copied: " prefix, strip "Quick Add: " prefix, strip parenthetical portions like "(150g)"
       - Return HistoryItem[] with: name, totalCount, lastLogged (ISO string), avgCalories, avgProtein, avgCarbs, avgFat

    2. `searchHistory(query: string, limit = 10): HistoryItem[]` — calls getRecentHistory with higher limit (50), then filters in JS where name.toLowerCase().includes(query.toLowerCase()), returns first `limit` matches

    3. `validateMacros(cal: number, protein: number, carbs: number, fat: number): { isValid: boolean; expected: number }` — exported pure function. expected = protein*4 + carbs*4 + fat*9. Tolerance: Math.max(expected * 0.1, 20). If all values are 0, return {isValid: true, expected: 0}.

    Export the HistoryItem interface:

    ```typescript
      lastLogged: string;

      avgProtein: number;
      avgCarbs: number;
      avgFat: number;
    }
    ```
