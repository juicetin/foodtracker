## Decisions Made
- **Per-item YOLO labels as primary:** Each DetectedItem.className uses the YOLO-assigned food name from GGCD (e.g., "Rice"), not the shared EfficientNet-Lite0 classifier label. The classifier runs for secondary confirmation and is logged in __DEV__ mode.
- **formatFoodLabel replaces formatClassLabel:** The new function handles GGCD naming conventions (hyphens like "airan-katyk", underscores like "pad_thai", spaces) by splitting on /[-_\s]+/ and title-casing each word.
- **Classifier as secondary confirmation only:** The EfficientNet-Lite0 classifier still runs when detections exist, providing a broader food taxonomy as a second opinion, but its result is logged rather than applied to items.
