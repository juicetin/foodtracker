## Decisions Made
- **Docker-based conversion:** TensorFlow lacks Python 3.14 wheels, so used tensorflow/tensorflow:2.18.0 Docker image with onnx2tf for the ONNX-to-TFLite conversion. Export script supports both native and Docker paths.
- **Dynamic range INT8 quantization:** Selected dynamic_range_quant variant from onnx2tf (3.6MB) which quantizes internal ops to INT8 while keeping float32 input/output. This is compatible with the existing pipeline's float32 preprocessing without any changes.
- **ONNX intermediate:** Ultralytics exports to ONNX successfully on Python 3.14 (no TF dependency), then Docker handles the ONNX->TFLite step.
