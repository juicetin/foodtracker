## Decisions Made
- Tiered USDA loading with graceful degradation: full CSV (7,793 foods) -> auto-download -> embedded 500-food subset ensures pipeline works offline
- Levenshtein distance with early termination at max_dist threshold for performance; only invoked after 5 faster strategies fail
- Jaccard token overlap (>=0.5) as primary fuzzy strategy, Levenshtein edit distance (<=2) on USDA first-word groups as secondary
- Pre-filters for Levenshtein: skip candidates with length difference >3 or first character ordinal difference >2
- Classifier/detector labels seeded as step 3 (before recipes, step 4) so recipe data can enrich label-seeded dishes
- Original model label strings registered as dish_alias with alias_type='model_label' for formatFoodLabel() matching
