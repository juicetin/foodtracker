Add a new Strategy 6 after the existing Strategy 5:

```python
# Strategy 6: Levenshtein fuzzy match against USDA descriptions
if not fdc_id:
    best_score = 0
    best_fdc = None
    name_tokens = set(name_lower.split())

    for usda_desc_lower, fid in usda_by_desc.items():
        # Token overlap score (Jaccard similarity)
        usda_tokens = set(usda_desc_lower.split(",")[0].strip().split())
        if not usda_tokens:
            continue
        overlap = len(name_tokens & usda_tokens)
        union = len(name_tokens | usda_tokens)
        jaccard = overlap / union if union > 0 else 0

        if jaccard >= 0.5 and jaccard > best_score:
            best_score = jaccard
            best_fdc = fid

    # Also try Levenshtein on the first word group of USDA descriptions
    if not best_fdc and len(name_lower) >= 4:
        min_dist = float('inf')
        for first_group, fid in usda_by_first.items():
            if abs(len(name_lower) - len(first_group)) > 3:
                continue  # Skip if length difference too large
            dist = _levenshtein_distance(name_lower, first_group)
            if dist <= 2 and dist < min_dist:
                min_dist = dist
                best_fdc = fid

    if best_fdc:
        fdc_id = best_fdc
```

Add a helper `_levenshtein_distance(s1, s2)` function (simple O(n*m) dynamic programming implementation -- only called for ingredients that didn't match via faster strategies, so performance is acceptable).

**Performance guard:** The fuzzy matching is only invoked for ingredients that failed all 5 existing strategies.
