## Decisions Made
- Implemented SymSpell inline (~230 lines) rather than using npm symspell-ex package (250 downloads/week, stale)
- Used Damerau-Levenshtein distance (supports transposition) for better typo correction (e.g., "pad thia" -> "pad thai")
- FTS5 prefix match tried first (fastest), then alias FTS5, then SymSpell fuzzy as final fallback
- KG service follows NutritionService patterns: raw SQL via op-sqlite execute(), camelCase result mapping, openNutritionDb for connection
