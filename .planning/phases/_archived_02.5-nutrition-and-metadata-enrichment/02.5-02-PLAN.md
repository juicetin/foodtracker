  <action>
    Create build_worldcuisines_metadata.py that:

    1. Downloads worldcuisines/food-kb from HuggingFace using the `datasets` library. If --input-dir is provided, read from local Parquet/JSON instead. Store downloaded data at ~/media/foodtracker-ml/nutrition-data/worldcuisines/ for caching.

    2. Creates a SQLite database with these tables:

    ```sql
    CREATE TABLE dishes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        english_name TEXT NOT NULL,
        normalized_name TEXT NOT NULL UNIQUE,
        cuisine TEXT,
        country TEXT,
        region TEXT,
        image_url TEXT
    );

    CREATE TABLE dish_translations (
        dish_id INTEGER REFERENCES dishes(id),
        language_code TEXT NOT NULL,
        translated_name TEXT NOT NULL,
        PRIMARY KEY (dish_id, language_code)
    );

    CREATE TABLE dish_aliases (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        dish_id INTEGER REFERENCES dishes(id),
        alias TEXT NOT NULL,
        language_code TEXT
    );

    CREATE INDEX idx_dishes_normalized ON dishes(normalized_name);
    CREATE INDEX idx_dishes_cuisine ON dishes(cuisine);

    CREATE VIRTUAL TABLE dishes_fts USING fts5(
        english_name,
        content=dishes,
        content_rowid=id
    );

    CREATE VIRTUAL TABLE aliases_fts USING fts5(
        alias,
        content=dish_aliases,
        content_rowid=id
    );
    ```

    3. For each dish in the dataset:
       - Extract english name, normalize to lowercase-hyphenated (e.g., "Pad Thai" -> "pad-thai")
       - Extract cuisine tag (e.g., "Thai", "Japanese", "Ethiopian")
       - Extract country and region if available
       - Insert translations for all available languages into dish_translations
       - Insert alternative names/aliases into dish_aliases

    4. Build FTS5 indexes, ANALYZE, VACUUM.

    5. CLI: `python build_worldcuisines_metadata.py [--input-dir /path/to/data] --output worldcuisines-metadata.db`

    6. Include a Python helper function `get_cuisine_for_class(db_path, normalized_name)` that looks up the cuisine tag for a classifier class name. This function will be useful for generating the class-to-nutrition mapping in Plan 03.

    Add `datasets` to knowledge-graph/requirements.txt if not already present (it's in training/requirements.txt but may not be in knowledge-graph/).

    Create test_worldcuisines_build.py with mock data (small list of dish dicts) testing all behaviors above. Do NOT download from HuggingFace in tests -- use fixture data.
