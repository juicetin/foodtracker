## Decisions Made
- EfficientNet-Lite0 INT8 (3.9MB) replaces AIY Food V1 (21MB) -- 5.4x smaller, food-only trained
- Binary gate removed because EfficientNet-Lite0 is already food-only (unlike AIY V1's 2024 generic classes)
- Food-101 fallback removed because its 101 classes are a strict subset of the new 335
- ImageNet normalization constants exported for downstream preprocessing use
