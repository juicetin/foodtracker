<objective>
Wire the EfficientNet-Lite0 classifier into the detection pipeline, replacing the 3-stage AIY pipeline (binary -> detect -> classify + food101 fallback) with a simplified 2-stage pipeline (detect -> classify) using ImageNet normalization and 335-class output.

Purpose: The binary gate existed because AIY Food V1 had 2024 generic classes (many non-food) and needed a separate food-vs-not-food check. EfficientNet-Lite0 is trained exclusively on food images, so a simple confidence threshold on its output serves the same purpose. Food-101 fallback is unnecessary because its 101 classes are a strict subset of the new 335 classes.

Output: Fully functional 2-stage pipeline with updated tests.
</objective>
