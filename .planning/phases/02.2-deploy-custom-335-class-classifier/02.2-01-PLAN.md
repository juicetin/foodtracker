<objective>
Deploy the trained EfficientNet-Lite0 INT8 model and 335-class labels as bundled assets, and update the type contracts and constants to reflect the simplified 2-stage pipeline (detect + classify, no binary gate, no Food-101 fallback).

Purpose: Establish the model files and type contracts that Plan 02 will wire into the inference pipeline. The binary gate is removed because EfficientNet-Lite0 is already food-only trained (unlike AIY Food V1 which had 2024 generic classes requiring a separate food-vs-not-food step). The Food-101 fallback is removed because its 101 classes are a strict subset of the new 335.

Output: New classifier model, labels, updated manifest, updated constants and types.
</objective>
