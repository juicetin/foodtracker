**Gathered:** 2026-03-13

<domain>
## Phase Boundary

Replace AIY Food V1 (192x192 uint8, 2024 generic classes) with our custom-trained EfficientNet-Lite0 (224x224 float32, 335 food-specific classes, 3.9MB INT8) in the app's detection pipeline. Remove the Food-101 fallback classifier (its 101 classes are a subset of the new 335). Build and verify on-device.

</domain>

<decisions>
## Implementation Decisions

### Model Files
- INT8 TFLite model at `/home/me/media/foodtracker-ml/exports/food2k_efficientnet_lite0_int8.tflite` (3.9MB) — deploy this one
- Labels at `/home/me/media/foodtracker-ml/exports/food2k_labels.json` (335 classes, adobo through zoni)
- Input: [1, 224, 224, 3] float32 NHWC, ImageNet normalization (mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])
- Output: [1, 335] float32 class logits

### Pipeline Changes
- Replace AIY Food V1 classify model with EfficientNet-Lite0
- Change classify preprocessing from 192x192 uint8 to 224x224 float32 with ImageNet normalization
- Remove binary gate model (AIY-specific) — EfficientNet-Lite0 is already food-only trained
- Remove Food-101 fallback classifier (food101.tflite + labels_food101.json) — no longer needed
- Keep YOLO11n COCO for detection (replaced by GGCD in Phase 2.3)

### Code Impact
- `apps/mobile/src/services/detection/constants.ts` — update input sizes, remove Food-101 constants
- `apps/mobile/src/services/detection/types.ts` — simplify ModelSet (remove food101, possibly binaryGate)
- `apps/mobile/src/services/detection/modelLoader.ts` — load new model, update require() paths
- `apps/mobile/src/services/detection/inferenceRouter.ts` — remove fallback logic, update normalization
- `apps/mobile/src/screens/DetectionScreen.tsx` — update preprocessing buffer sizes
- `apps/mobile/assets/models/` — swap model files, update manifest

### Claude's Discretion
- Whether to keep binaryGate as a separate step or fold food-vs-not-food into classifier confidence threshold
- Test strategy for verifying classification accuracy on-device
- Whether to keep FP32 model as a debug option

</decisions>

<specifics>
## Specific Details

- Training results: 74.17% top-1, 92.14% top-5 on 335 classes (Food-101 + UEC-256 merged)
- The 335 classes cover: Japanese (ramen, udon, soba, tempura, sushi), Thai (pad thai, green curry), Vietnamese (pho), Chinese (kung pao chicken, chow mein), Western (pizza, hamburger, steak), plus many more
- Model was trained with: EfficientNet-Lite0, two-phase (5 frozen + 25 unfrozen), cosine annealing, label smoothing 0.1, AdamW, mixed precision
- All exports at `/home/me/media/foodtracker-ml/exports/`

</specifics>
