  <action>
    Extend packManager.ts to check AI pack availability before falling back to R2 download.

    **1. Add resolveAiPackPath function:**
    ```typescript
    import { Platform } from 'react-native';

    async function resolveAiPackPath(packId: string, filename: string): Promise<string | null> {
      if (Platform.OS !== 'android') return null;
      try {
        const { aiPackDeliveryModule } = require('../../modules/ai-pack-delivery/src/aiPackDeliveryModule');
        const status = await aiPackDeliveryModule.getPackStatus('ml-models');
        if (status === 'completed') {
          const basePath = await aiPackDeliveryModule.getPackLocation('ml-models');
          if (basePath) return `${basePath}/${filename}`;
        }
        return null;
      } catch {
        return null;
      }
    }
    ```

    Use `require()` (not import) for the AI pack module to avoid breaking iOS builds where the native module is a no-op stub. The try/catch ensures graceful fallback if the module fails.

    **2. Modify downloadPack (or the model loading path):**
    At the top of the download flow (before checking if already installed, before hitting R2), call `resolveAiPackPath(pack.id, expectedFilename)`. If it returns a path, skip R2 download entirely and use the AI pack path.

    Specifically, add to the pack resolution logic:
    - Before downloading from R2, check `resolveAiPackPath`
    - If AI pack path exists and the file is accessible, return it as the installed path
    - If AI pack path is null, proceed with existing R2 download logic
    - Log in __DEV__ which path was used: "Using AI pack path" vs "Falling back to R2 download"

    **3. Update the Phase 1 comment** at the top of packManager.ts:
    Change "Phase 6: Platform-native delivery (Play Asset Delivery / iOS ODR) as optimization." to "Phase 6: AI pack resolution added -- checks Play for On-Device AI before R2 fallback."

    **Do NOT change** the R2 download logic, pack verification, or any existing functionality. This is purely additive -- a new resolution step before the existing flow.
