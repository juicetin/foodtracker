  <action>
Create `training/export_embedding.py` that:

1. **PyTorch wrapper class `SentenceEmbedder(nn.Module)`:**
   - Loads `sentence-transformers/all-MiniLM-L6-v2` via `AutoModel.from_pretrained`
   - `forward(input_ids: int32[1,128], attention_mask: int32[1,128])` returns float32[1,384]
   - Mean pooling: expand attention_mask to token_embeddings shape, sum masked embeddings, divide by mask sum (clamp min=1e-9)
   - L2 normalize: `torch.nn.functional.normalize(pooled, p=2, dim=1)`

2. **ONNX export function:**
   - `torch.onnx.export` with opset_version=13
   - input_names=["input_ids", "attention_mask"], output_names=["embedding"]
   - Fixed shapes (no dynamic_axes) — batch=1, seq_len=128
   - Dummy inputs: `torch.randint(0, 30522, (1, 128), dtype=torch.int32)`, `torch.ones(1, 128, dtype=torch.int32)`

3. **Docker-based onnx2tf conversion (primary path):**
   - Follow export_ggcd_detect.py Docker pattern
   - Image: `tensorflow/tensorflow:2.18.0`
   - Install: `pip install onnx2tf onnx`
   - Command: `onnx2tf -i embedding.onnx -o tflite_out -oiqt` (INT8 dynamic range quantization)
   - Copy the `*_integer_quant.tflite` or `*_dynamic_range_quant.tflite` output to final path

4. **Vocab extraction function:**
   - `AutoTokenizer.from_pretrained("sentence-transformers/all-MiniLM-L6-v2")`
   - `tokenizer.get_vocab()` returns dict with 30522 entries
   - Write to `vocab_embedding.json` with `json.dump(vocab, f)` (no indent, minimal size)

5. **Validation function (--validate flag):**
   - Load sentence-transformers model: `SentenceTransformer("all-MiniLM-L6-v2")`
   - Load TFLite model via `ai-edge-litert` (try/except fallback to `tflite-runtime`)
   - Test 5 food name pairs:
     - "chicken breast" — expect similar to USDA "chicken, broilers or fryers, breast"
     - "tonkatsu" — expect similar to "pork, loin"
     - "pad thai" — expect similar to "noodles"
     - "chocolate cake" — expect dissimilar to "chicken breast"
     - "grilled salmon" — expect similar to "salmon"
   - For each: compute cosine similarity between sentence-transformers output and TFLite output
   - Assert cosine similarity > 0.99 for identical text (same input to both models)
   - Print cosine distance matrix for the 5 foods as quality check

6. **Asset copy function (--deploy flag):**
   - Copy embedding.tflite to `apps/mobile/assets/models/embedding.tflite`
   - Copy vocab_embedding.json to `apps/mobile/assets/data/vocab_embedding.json`
   - Update model_manifest.json: add entry with id="minilm-embedding-v1", stage="embedding", file="embedding.tflite", format="tflite", quantisation="int8", embeddingDim=384, maxSeqLen=128

7. **CLI interface:**
   - `--docker` flag (default True) for Docker-based conversion
   - `--validate` flag to run validation after export
   - `--deploy` flag to copy assets to mobile app
   - `--output-dir` with default `training/exports/embedding/`
   - Follow argparse pattern from export_ggcd_detect.py

Python deps (installed in venv/Docker, not npm): torch, transformers, sentence-transformers, onnx, numpy, ai-edge-litert (for validation)
