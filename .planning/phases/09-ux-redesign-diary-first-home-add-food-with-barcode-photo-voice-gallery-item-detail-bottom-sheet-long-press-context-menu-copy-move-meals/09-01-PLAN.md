     - Maps 'snack' to 'snacks' (normalize)

   - Import `opsqlite` from `../../../db/client`
   - Use the `generateId()` pattern from the codebase (UUID v4 random)
   - Export `function copyEntryToDate(sourceEntryId: string, targetDate: string, targetMealType?: string): string` that:
     - Reads source food_entry row
     - INSERTs new food_entry with new id, targetDate, targetMealType (or source meal_type)
     - Copies all scanned_dishes rows (new IDs, referencing new entry_id)
     - Copies all ingredients rows (new IDs, referencing new entry_id + new dish_id)
     - Does NOT copy photos (they reference original files)
     - Returns new entry id
   - Export `function moveEntryToMeal(entryId: string, newMealType: string): void` that UPDATEs food_entries.meal_type
   - Export `function copyAllEntriesFromDate(sourceDate: string, targetDate: string, filterMealType?: string): number` that copies all entries from one date to another, optionally filtered by meal type
