1. **Update DiaryHomeScreen.tsx** to render all three sheets and handle their actions:

   Add imports:
   - `import { ItemDetailSheet } from '../components/sheets/ItemDetailSheet';`
   - `import { ContextMenuSheet } from '../components/sheets/ContextMenuSheet';`
   - `import { MealGroupMenuSheet } from '../components/sheets/MealGroupMenuSheet';`
   - `import { copyEntryToDate, moveEntryToMeal, copyAllEntriesFromDate } from '../services/diary/copyMoveService';`
   - `import { addFavourite } from '../services/favourites';`
   - `import * as Clipboard from 'expo-clipboard';`
   - `import { Alert } from 'react-native';`

   The state variables selectedEntryId, contextMenuEntry, menuMealGroup already exist from Plan 02.

   Render sheets OUTSIDE the GestureDetector wrapper (to avoid gesture conflicts per anti-pattern rule):
   - `<ItemDetailSheet entryId={selectedEntryId} onDismiss={() => setSelectedEntryId(null)} onEdit={handleEdit} onDelete={handleDelete} />`
   - `<ContextMenuSheet entry={contextMenuEntry} onDismiss={() => setContextMenuEntry(null)} onAction={handleContextAction} />`
   - `<MealGroupMenuSheet mealGroup={menuMealGroup} selectedDate={selectedDate} onDismiss={() => setMenuMealGroup(null)} onAction={handleMealGroupAction} />`

   Action handlers:

   `handleEdit(entryId: string)`:
   - setSelectedEntryId(null) (dismiss detail sheet first)
   - navigation.navigate('EntryDetail', { entryId })

   `handleDelete(entryId: string)`:
   - setSelectedEntryId(null)
   - Alert.alert('Delete Item?', 'This will remove the item from your diary.', [
       { text: 'Cancel', style: 'cancel' },
       { text: 'Delete', style: 'destructive', onPress: () => { deleteEntry(entryId); refresh(); } }
     ])
   - Use useFoodLogStore().softDeleteEntry or direct SQL: `UPDATE food_entries SET is_deleted = 1 WHERE id = ?`

   `handleContextAction(action: ContextMenuAction, entry: DiaryEntry)`:
   - setContextMenuEntry(null) (dismiss context menu)
   - Switch on action:
     - 'copy-clipboard': format entry as text (name, cal, P/C/F), Clipboard.setStringAsync(text), show brief "Copied" toast or Alert
     - 'copy-day': show a CalendarPicker or date input Alert to pick target date, then call copyEntryToDate(entry.id, targetDate), refresh()
     - 'move-meal': show an Alert/ActionSheet with meal type options (Breakfast/Lunch/Dinner/Snacks), then call moveEntryToMeal(entry.id, selectedMealType), refresh()
     - 'favorite': call addFavourite({ name: entry.dishes[0]?.name, calories: entry.totalCalories, protein: entry.totalProtein, carbs: entry.totalCarbs, fat: entry.totalFat }), show brief confirmation
     - 'delete': same as handleDelete(entry.id)

   `handleMealGroupAction(action: MealGroupAction, mealGroup: MealGroup)`:
   - setMenuMealGroup(null)
   - Switch on action:
     - 'copy-from-date': show CalendarPicker/date Alert, then call copyAllEntriesFromDate(sourceDate, selectedDate, mealGroup), refresh()
     - 'copy-yesterday': get yesterday's date, call copyAllEntriesFromDate(yesterday, selectedDate, mealGroup), refresh(), show "Copied X items" Alert
     - 'save-template': show Alert with "Coming soon — meal templates" (placeholder for future, per deferred ideas)

   For date picking in context menu actions ('copy-day', 'copy-from-date'):
   - Reuse CalendarPicker component from Plan 02 in a modal state
   - Add state: `datePickerContext: { action: string; entryId?: string; mealGroup?: MealGroup } | null`
   - When CalendarPicker selects a date, execute the pending action using datePickerContext

2. Ensure the sheets render at the same level as the SafeAreaView children (outside ScrollView but inside the component), wrapped in a `GestureHandlerRootView` if not already present.
