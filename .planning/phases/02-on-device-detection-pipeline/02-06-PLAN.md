The TS error: `TFLiteModel.run()` returns `Promise<ArrayBufferLike[]>`. `ArrayBufferLike` is `ArrayBuffer | SharedArrayBuffer`.     Implementation:

         2. Read the file as base64 via `expo-file-system`
         3. Decode base64 to Uint8Array
         4. Use a lightweight embedded JPEG decoder (or if too complex, use the raw JPEG bytes with a note that full pixel decoding will be validated on-device with model packs)
