       ```typescript
       export const weightEntries = sqliteTable('weight_entries', {
         id: integer('id').primaryKey({ autoIncrement: true }),
         date: text('date').notNull().unique(), // YYYY-MM-DD
         weightKg: real('weight_kg').notNull(),
         source: text('source').notNull(), // 'manual' | 'health_connect'
         healthConnectId: text('health_connect_id'),

       });
       ```

    3. Create healthConnectService.ts:
       - `isHealthConnectAvailable(): Promise<boolean>` -- wraps getSdkStatus in try/catch, returns false on any error (handles Android < 14 without Health Connect app)
       - `initHealthConnect(): Promise<void>` -- calls initialize()
       - `requestWeightPermission(): Promise<boolean>` -- requestPermission([{ accessType: 'read', recordType: 'Weight' }])
       - `readWeightRecords(startDate: Date, endDate: Date): Promise<{ date: string; weightKg: number; healthConnectId: string }[]>` -- calls readRecords('Weight', { timeRangeFilter }), maps records to simple objects

    4. Create weightTrendService.ts (pure functions, no side effects):
       - `WeightEntry` type: `{ date: string; weightKg: number; source: 'manual' | 'health_connect' }`
       - `emaSmooth(weights: number[], alpha?: number): number[]` -- default alpha=0.15. Standard EMA: smoothed[0]=weights[0], smoothed[i]=alpha*weights[i]+(1-alpha)*smoothed[i-1]
       - `calculateWeightTrend(entries: WeightEntry[]): WeightTrend` where WeightTrend = { raw: number[]; smoothed: number[]; dates: string[]; latestKg: number | null; trendDirection: 'up' | 'down' | 'stable' }. Trend direction: compare last smoothed vs smoothed 7 entries ago (or first if <7). Stable if diff < 0.2kg.

    5. Update app.json: add expo-health-connect and react-native-health-connect config if needed. Add `android.permissions` for `android.permission.health.READ_WEIGHT` if not using the config plugin approach.
