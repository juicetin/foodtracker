  <action>
    1. **ScaleInputScreen.tsx**: New screen shown when user taps "Add scale weight" from detection results or ProfileScreen.
       - State: scaleReading (from OCR), manualWeight (TextInput), selectedContainer (Container | null), netWeight (computed)
       - On mount: if photoUri param exists, call readScaleWeight(photoUri) and display result
       - Show OCR result with confidence indicator (green=high, yellow=low)
       - Manual weight TextInput always visible (pre-filled with OCR result if available, editable)
       - Container selector: FlatList of getContainers() sorted by frequency. Tap to select. "Add Container" button opens inline form (name + weight TextInputs)
       - Net weight display: grossWeight - selectedContainer.weightGrams (via applyTare)
       - "Confirm" button returns net weight to caller via navigation params
       - Keyboard type: 'decimal-pad' for weight inputs

    2. **WeightTrendScreen.tsx**: New screen accessible from ProfileScreen.
       - On mount: call useWeightStore.loadEntries()
       - Display raw weight data points as dots and EMA smoothed line (use react-native's built-in Views for simple chart -- plot dots at scaled Y positions within a ScrollView, or use a lightweight approach with Views)
       - If no weight entries: show empty state with "Add your first weight" prompt
       - Manual weight entry: date picker + weight input + "Add" button at top
       - If Health Connect enabled: "Sync Now" button that calls syncFromHealthConnect()
       - Show trend direction indicator (arrow up/down/flat) with latest smoothed value
       - NOTE: For v1, a simple list-based trend display is acceptable if chart implementation is too complex. Show: date, raw weight, smoothed weight, trend arrow. A proper chart (victory-native, react-native-chart-kit) can be added in gap closure.

    3. **ProfileScreen.tsx extensions**: Add three new sections:
       - **Notifications section**: Toggle for notificationsEnabled, time picker (hour:minute) for notification time. On toggle on: call requestNotificationPermission() then scheduleDailyNotification(). On toggle off: call cancelDailyNotification(). On time change: call rescheduleWithFreshContent().
       - **Container Weights section**: "Manage Containers" button navigating to a simple list (can be inline or separate screen). Show container list with name, weight, usage count. Swipe-to-delete or delete button.
       - **Health & Weight section**: Toggle for healthConnectEnabled. On enable: call initHealthConnect() + requestWeightPermission(). "View Weight Trend" button navigating to WeightTrendScreen. Show isHealthConnectAvailable() status (if unavailable, show "Install Health Connect" message for Android < 14).

    4. **DetectionScreen.tsx**: After detection results, if a dish card shows ingredient list, no change needed (DishCard already renders ingredients). However, add a "Scale Weight" button in the detection results footer (next to Log Meal) that navigates to ScaleInputScreen with the current photoUri. When returning from ScaleInputScreen, apply the net weight to the selected dish's portion.

    5. **AppNavigator.tsx**: Add ScaleInputScreen and WeightTrendScreen to the navigation stack.

    Style all new UI consistent with existing screens (same padding, font sizes, color tokens from existing StyleSheets).
