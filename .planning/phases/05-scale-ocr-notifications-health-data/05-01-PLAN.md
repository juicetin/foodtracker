  <action>
    Create hiddenIngredientsService.ts with a single export: `enrichDishesWithKgIngredients(dishes: ScannedDish[]): Promise<ScannedDish[]>`.

    Logic:
    - For each dish, if `dish.ingredients.length === 0` (VLM failed to provide ingredients):
      1. Call KG `searchDish(dish.name)` to find the dish
      2. If found, call `getCanonicalRecipe(dishId)` then `getRecipeIngredients(recipeId)`
      3. Map KG ingredients to ScannedIngredient[] with `kgInferred: true` flag
      4. Nutrition values come from the KG ingredient's USDA per-100g data scaled to quantity_grams
    - If dish already has ingredients, return unchanged (VLM ingredients take priority)
    - Add a `kgInferredIngredients?: string[]` field to ScannedDish type (optional, for UI display of "Contains: ...")

    Wire into vlmPipeline.ts `scanFood()`: after VLM identification, call `enrichDishesWithKgIngredients()` on the result dishes before returning. This ensures both VLM-identified and text-fallback dishes get KG ingredient enrichment.

    DO NOT modify the detection store or UI in this task -- that's existing DishCard which already renders ingredients.
  </action>
