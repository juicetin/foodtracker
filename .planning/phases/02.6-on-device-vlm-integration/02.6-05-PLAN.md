         - If `!vlmService.isReady`, return items unchanged (VLM not available)
         - Call `vlmService.identify(photoUri, userText)` wrapped in try/catch

         - For each VLM dish, find best matching YOLO item by string similarity between VLM dish.name and item.className
         - Similarity strategy: lowercase both, check if one contains the other (substring match first), then fall back to word overlap ratio
         - If similarity is too low (< 0.3 word overlap), try positional matching (first VLM dish -> first YOLO item by bbox area, etc.)
         - Return a Map<itemId, VlmDish> of matched pairs
         - Log unmatched VLM dishes in __DEV__ mode

       - Internal helper `computeWordOverlap(a: string, b: string): number`:
         - Split both strings into words
         - Count words in common
         - Return overlap / max(wordsA, wordsB)
