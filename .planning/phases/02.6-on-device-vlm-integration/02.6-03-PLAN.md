<objective>
Implement VlmService singleton that manages llama.rn context lifecycle (init, infer, release) and prompt engineering for food identification.

Purpose: Core VLM inference abstraction. Encapsulates all llama.rn interaction behind a clean API that the pipeline orchestrator and UI can call without knowing llama.rn internals. Handles the hard parts: lazy loading, multimodal init, grammar-constrained output, inactivity timeout, error recovery.
Output: Working VlmService with init/identify/release lifecycle, prompt builder, barrel exports.

Note on DET-03: Gemini Nano via AICore is architecturally separate from llama.rn VLM. DET-03 is assigned here because VlmService establishes the abstraction layer that a future Gemini Nano adapter would plug into. The actual AICore integration is deferred to a future phase.
</objective>

    - vlmService.isReady returns true after init, false after release

  <action>
    1. Create `apps/mobile/src/services/vlm/vlmService.ts`:
       - Import `initLlama` from `llama.rn` and types from `./vlmTypes`
       - Import `buildFoodPrompt` from `./vlmPrompts`
       - Import `FOOD_IDENTIFICATION_SCHEMA, VlmFoodResult` from `./vlmTypes`
       - Singleton object (not class -- matches project convention of object literals like PackManager):
         ```typescript
         export const vlmService = {
           // Private-ish state (module-level variables)
           // context: LlamaContext | null
           // releaseTimer: NodeJS.Timeout | null
           // isReady: boolean (getter)

           async init(modelPath: string, mmprojPath: string): Promise<void> { ... },
           async identify(imageUri: string, userText?: string): Promise<VlmFoodResult> { ... },
           async release(): Promise<void> { ... },
           get isReady(): boolean { ... },
         };
         ```
       - `init()`:
         - If context already exists, return early (idempotent)
         - Call `initLlama({ model: modelPath, n_ctx: 2048, n_gpu_layers: 99, use_mlock: true, ctx_shift: false })`
         - Then call `context.initMultimodal({ path: mmprojPath, use_gpu: true })`
         - Store context in module-level variable
         - If any step fails, ensure context is null (clean state)
       - `identify()`:
         - If no context, throw Error('VLM not initialized. Call init() first.')
         - Reset inactivity timer (clearTimeout + setTimeout 60s -> release)
         - Build prompt via `buildFoodPrompt(userText)`
         - Call `context.completion()` with messages array containing image_url and text content parts
         - Use `response_format: { type: 'json_schema', json_schema: FOOD_IDENTIFICATION_SCHEMA }`
         - Use `n_predict: 256, temperature: 0.1` (low temp for structured output)
         - Parse result.text as JSON, return as VlmFoodResult
         - Wrap JSON.parse in try/catch -- if parsing fails, return `{ dishes: [] }` (graceful fallback)
       - `release()`:
         - Clear inactivity timer
         - If context exists, call context.release(), set to null
       - `isReady` getter: returns `context !== null`
