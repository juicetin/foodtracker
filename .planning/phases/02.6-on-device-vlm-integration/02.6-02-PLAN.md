<objective>
Overhaul PackManager to support large file streaming downloads (no OOM on 300MB+) and paired file packs (model GGUF + mmproj GGUF) required for VLM delivery.

Purpose: Current PackManager uses `fetch().arrayBuffer()` which buffers the entire download into RAM -- this will crash on 300MB+ VLM downloads. Streaming via `createDownloadResumable` fixes this. VLM packs also need two files tracked as one logical pack.
Output: Streaming PackManager with VLM pack type support, paired file downloads, extended DB schema.
</objective>
