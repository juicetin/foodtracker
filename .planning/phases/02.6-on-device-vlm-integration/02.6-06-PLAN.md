<task type="auto">
  <name>Task 1: VLM download screen with tier auto-selection and progress</name>
  <files>apps/mobile/src/screens/VlmDownloadScreen.tsx, apps/mobile/src/navigation/AppNavigator.tsx</files>
  <action>
    1. Create `apps/mobile/src/screens/VlmDownloadScreen.tsx`:
       - Import `detectVlmTier, getVlmTierConfig, VLM_TIER_CONFIG` from services/vlm
       - Import `PackManager` from services/packs/packManager
       - Import `PackEntry, DownloadProgress` types
       - Screen layout:
         - Header: "VLM Model" with subtitle showing detected tier and device RAM
         - Tier info card: shows model name, download size (formatted as MB/GB), RAM requirement
         - If tier is 'none': show message "Your device has less than 4GB RAM. VLM is not available."
         - Status section:
           - "Not installed" -> show "Download" button
           - "Downloading" -> show progress bar with percentage and MB downloaded/total
           - "Installed" -> show checkmark with installed date, "Delete" button to remove
         - Error handling: show error message with "Retry" button if download fails

       - State management (useState):
         - `status: 'checking' | 'not-installed' | 'downloading' | 'installed' | 'error'`
         - `progress: DownloadProgress | null`
         - `error: string | null`

       - On mount (useEffect):
         - Call `detectVlmTier()` to determine tier
         - If 'none', set status to a disabled state
         - Otherwise, check `PackManager.isPackInstalled(tierConfig.modelId)` to set initial status

       - Download handler:
         - Create a PackEntry from VLM_TIER_CONFIG values:
           - id: tierConfig.modelId
           - name: tierConfig.modelFile (human-readable)
           - type: 'vlm'
           - version: '1.0.0'
           - sizeBytes: tierConfig.modelSize
           - sha256: '' (skip integrity check for initial release -- models from HuggingFace, add hashes later)
           - url: construct HuggingFace direct download URL from model file name:
             For budget: `https://huggingface.co/ggml-org/SmolVLM-256M-Instruct-GGUF/resolve/main/SmolVLM-256M-Instruct-Q8_0.gguf`
             For mid: similar pattern with SmolVLM-500M
             For high: similar pattern with SmolVLM2-2.2B
           - mmprojUrl: similar HuggingFace URL for mmproj file
           - mmprojSizeBytes: tierConfig.mmprojSize
           - mmprojSha256: '' (same as above)
           - description: `SmolVLM ${tier} tier for food identification`
         - Call `PackManager.downloadPack(packEntry, onProgress)`
         - Update progress state during download
         - On success, set status to 'installed'
         - On error, set status to 'error' with error message

       - Delete handler:
         - Call `PackManager.deletePack(tierConfig.modelId)`
         - Set status to 'not-installed'

       - Format helpers: `formatBytes(bytes)` -> "175 MB", "1.11 GB"

    2. Update `apps/mobile/src/navigation/AppNavigator.tsx`:
       - Add VlmDownloadScreen to the navigator stack
       - Add a navigation entry accessible from settings/profile area (look at existing navigation pattern)
       - If there's a settings screen, add a "VLM Model" row that navigates to VlmDownloadScreen
       - If no settings screen exists, add it as a tab or accessible via a button on the home screen

    Note on SHA-256: Setting sha256 to empty string will skip the hash verification in PackManager (the hash check compares against pack.sha256, which is empty). This is acceptable for the initial release since we're downloading directly from HuggingFace official repos. Proper hash verification should be added when models are hosted on the project's R2 bucket.
