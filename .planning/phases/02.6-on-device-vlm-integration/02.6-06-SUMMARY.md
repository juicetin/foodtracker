## Decisions Made
- VLM download screen uses `detectVlmTier()` for automatic tier selection -- no manual tier picker; device RAM determines the SmolVLM variant
- Detection gated behind VLM availability -- YOLO-only fallback removed entirely because YOLO labels are unreliable for food identification (e.g., ramen classified as "egg")
- `vlmPipeline.ts` throws if VLM not ready instead of silently returning bad labels -- fail-fast for correctness
- E2E verification on physical device deferred -- emulator has insufficient RAM for VLM model download; emulator validation confirmed UI and tier detection work correctly
