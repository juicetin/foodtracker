### Human Verification Required

#### 1. Full VLM Download and Inference Pipeline

**Test:** On a physical Android device with >= 4GB RAM, navigate to Profile -> VLM Model, observe tier auto-selection, tap Download, and wait for completion. Then navigate to DetectionScreen, take a food photo.
**Expected:** Tier shows correct SmolVLM variant for device RAM. Download shows percentage progress (e.g., "34% -- 125 MB / 365 MB"). After download, detection flow runs: YOLO labels appear immediately, "Refining..." badge appears, labels update in-place with VLM-refined names.
**Why human:** Emulator (emulator-5558) confirmed to have insufficient RAM for VLM model download. llama.rn native inference requires actual device hardware.

#### 2. Progressive Refinement Visual Flow

**Test:** After taking a food photo with the VLM pack installed, observe the label update sequence in DetectionScreen.
**Expected:** YOLO labels appear first (e.g., "egg"), the "Refining..." badge appears in the header with pulsing animation, then labels update to VLM-refined names (e.g., "ramen" or "carbonara"). The update is in-place — no screen reload.
**Why human:** Async state update sequence requires live VLM inference timing to observe. Cannot verify temporal ordering of async updates programmatically.

#### 3. MealTextInput Re-Refinement

**Test:** With food detected and VLM loaded, type "pad thai with shrimp" in the meal description text field.
**Expected:** After ~500ms (debounce), VLM re-runs with the text context and labels update to more specific identifications. The "Refining..." badge reappears during re-run.
**Why human:** Requires live VLM inference for the re-run. Debounce timing requires real device conditions.

#### 4. VLM Unavailable Redirect Flow

**Test:** On a clean install (no VLM pack) with a device that has >= 4GB RAM, open DetectionScreen.
**Expected:** The screen shows "AI Model Required" with the message "Download the AI model to identify foods from photos." and a "Download AI Model" button. Tapping the button navigates to VlmDownloadScreen.
**Why human:** Requires a device in a specific state (VLM-capable but pack not yet downloaded) to test the gating logic end-to-end.
