## Decisions Made
- Word overlap matching (substring check first, then word ratio with 0.3 threshold) for VLM-to-YOLO dish pairing, with positional fallback for low-confidence matches
- Debounced 500ms re-refinement when user types meal text and VLM is ready
- patch-package used to fix llama.rn v0.11.4 ESM/CJS config plugin issue (withLlama uses `require` but Expo plugin system expects ESM-compatible)
- VLM initialization is lazy (triggered on first detection results), not at app boot, to avoid startup cost
