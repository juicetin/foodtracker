  <action>
    **EntryDetailScreen.tsx -- "Save as Recipe" button:**
    1. Import `saveEntryAsRecipe` from recipeService
    2. Add state: `recipeNameModalVisible`, `recipeName`, `recipeServings`
    3. Add a "Save as Recipe" Pressable button alongside the existing "Save to Favourites" button (same row, same style pattern). Use Ionicons `book-outline` icon with purple (#7C3AED) color. Only show when `!editing && entry.dishes.length > 0`.
    4. On press: auto-suggest recipe name from dish names (`entry.dishes.map(d => d.name).join(' + ')`). If entry has VLM recipe_name data in notes/metadata, prefer that.
    5. Show a cross-platform Modal (NOT Alert.prompt -- it's iOS-only) with:
       - TextInput for recipe name (pre-filled with suggestion, user can override per locked decision)
       - TextInput for servings (default "1", numeric keyboard)
       - "Save" and "Cancel" buttons
    6. On Save: call `saveEntryAsRecipe(entry.id, recipeName.trim(), parseInt(recipeServings) || 1)`. Show success Alert. Close modal.

    **RecipeScreen.tsx -- Enhanced list with photo, macros, search, edit versioning:**
    1. Import `searchRecipes`, `updateRecipeWithVersioning` from recipeService
    2. Add search bar at top (TextInput with magnifying glass icon, same pattern as FoodSearchScreen)
    3. Update recipe list item rendering:
       - Show `recipe.photoUri` as a small Image thumbnail (40x40 rounded) on the left, fallback to Ionicons `restaurant-outline` placeholder
       - Show per-serving macros: `Math.round(recipe.totalCalories / (recipe.servings || 1))` Cal, P/F/C per serving
       - Show `recipe.timesUsed` as "Used N times" subtitle text
    4. Filter recipes by search query using `searchRecipes(query)` when query length >= 2, else show `loadRecipes()`
    5. Recipe tap behavior (1-2 tap re-log per locked decision):
       - Read uxMode from usePreferencesStore
       - If `uxMode === 'zero-effort'`: immediately call `logRecipeAsEntry(recipe.id, autoDetectMealType())`, show success toast, refresh diary
       - If `uxMode === 'confirm-only'`: show compact Alert with recipe name + macros, "Log 1 serving?" with serving count picker, Confirm/Cancel
       - If `uxMode === 'guided-edit'`: navigate to recipe detail/builder view (existing behavior)
    6. In builder/detail view, add versioning on save:
       - When user edits ingredients and taps Save, show Alert with two choices per locked decision:
         - "Update All" -- calls `updateRecipeWithVersioning(recipeId, ingredients, 'update-all')`. Show warning: "This will update N diary entries"
         - "Save as New" -- calls `updateRecipeWithVersioning(recipeId, ingredients, 'save-as-new')`. Navigates to new recipe.
       - Measuring by servings AND/OR weight: add a servings input field in the builder view. Show both total recipe nutrition and per-serving nutrition.

    **FoodSearchScreen.tsx -- Recipe results in search:**
    1. Import `searchRecipes` from recipeService
    2. Add `'recipe'` to the SearchResult `source` union type
    3. In `doSearch()`, after history matches but before KG search, add:
       ```
       const recipeMatches = searchRecipes(trimmed, 5);
       for (const r of recipeMatches) {
         unified.push({
           id: `recipe-${r.id}`,
           name: r.name,
           calorieHint: Math.round(r.totalCalories / (r.servings || 1)),
           source: 'recipe',
         });
       }
       ```
    4. In result rendering, show a "Recipe" badge (small purple pill) for `source === 'recipe'` items
    5. When user selects a recipe result: call `logRecipeAsEntry` with the recipe ID (respecting uxMode for confirmation)

    **ProfileScreen.tsx -- UX Mode selector:**
    1. Import `usePreferencesStore` and `UxMode` type
    2. Add a "Logging Mode" section in the profile/settings area
    3. Show three options as a segmented control or radio group:
       - "Zero-effort" -- auto-log, review later
       - "Confirm" -- review before logging (default)
       - "Guided" -- step-by-step editing
    4. On selection: call `setUxMode(mode)`
    5. Current selection highlighted
