### Gaps Summary

One gap blocks full goal achievement: `triggerForegroundDrain` in `galleryScanScheduler.ts` was not updated when `DrainResult` gained the `entriesCreated` field. The store's local `ScanResult` interface was correctly updated to require `entriesCreated`, but the return type annotation on `triggerForegroundDrain` (line 61) still declares the old three-field shape. TypeScript raises TS2741 at `useGalleryScanStore.ts:64` because the narrower return type cannot satisfy the store's updated interface.

The fix is a one-line change to `galleryScanScheduler.ts` line 61: add `entriesCreated: number` to the Promise return type annotation. The actual runtime data is correct because `drainScanQueue` does return `entriesCreated` -- this is a type annotation omission only.
