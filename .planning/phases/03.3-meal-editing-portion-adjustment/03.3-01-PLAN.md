    **editSessionManager.ts** — Command pattern undo/redo:
    - Define EditCommand interface: { execute(): void; undo(): void; description: string }
    - Define EditSession: { commands: EditCommand[]; pointer: number; originalSnapshot: EntrySnapshot | null }
    - EntrySnapshot is a deep clone of the full entry state (dishes + ingredients) for Reset button
    - createEditSession(snapshot: EntrySnapshot): EditSession
    - executeCommand(session, command): push command, increment pointer, call command.execute()
    - undo(session): call commands[pointer].undo(), decrement pointer
    - redo(session): increment pointer, call commands[pointer].execute()
    - canUndo/canRedo: pointer-based checks
    - reset(session): restore originalSnapshot to DB by calling entryEditorService functions
    - Concrete command classes: ChangeWeightCommand (calls updateIngredientWeight + recalculateEntryTotals), AddIngredientCommand (calls addIngredient/removeIngredient), RemoveIngredientCommand (calls removeIngredient/addIngredient with saved data), RenameIngredientCommand (calls updateIngredientName), RenameDishCommand (calls updateDishName)
    - Each command stores old+new values for bidirectional execution

    **useEditSession.ts** — React hook:
    - Wraps editSessionManager with useState for reactivity
    - Returns: { executeCommand, undo, redo, canUndo, canRedo, reset, commandCount }
    - Triggers re-render on each command execution for UI update

    **ServingSizeSelector.tsx** — Inline portion picker replacing EditableWeight:
    - Props: { ingredientId: string; ingredientName: string; currentAmountG: number; onWeightChange: (grams: number) => void }
    - Row layout: [current amount display] [serving size dropdown button]
    - Tapping the dropdown opens a small picker (not bottom sheet, just a dropdown overlay) with options:
      - KG standard portions if available (query KG by ingredient name for portions like "1 cup = 240g", "1 tbsp = 15g")
      - Common portions: "100g", "1 serving" (uses current amount as 1 serving)
      - "Custom" option opens free-form gram TextInput
    - Selecting a portion option calls onWeightChange(grams)
    - Debounce free-form input 300ms before calling onWeightChange per locked decision (real-time recalc)

    **IngredientSearchSheet.tsx** — Bottom sheet for adding ingredients via search:
    - Props: { visible: boolean; entryId: string; dishId: string; onAdd: (ingredient: IngredientUpdate) => void; onClose: () => void }
    - Uses @gorhom/bottom-sheet with snap points at ['60%', '90%']
    - TextInput search bar at top
    - On type (debounced 300ms): search KG via searchDish() + OFF via searchProducts() simultaneously
    - Results list: name, cal/100g, P/F/C per 100g, source badge (KG/OFF)
    - Tapping a result: auto-fills ingredient name + nutrition from KG calculateDishNutrition (default 100g portion)
    - "Manual Entry" button at bottom of results: opens inline form with name, grams, cal, protein, carbs, fat fields (same pattern as QuickAddScreen)
    - On confirm: calls onAdd() with populated IngredientUpdate

    **PhotoViewer.tsx** — Full-screen modal photo viewer:
    - Props: { photos: Array<{ uri: string }>; initialIndex: number; visible: boolean; onClose: () => void }
    - Full-screen Modal with black background

    - Horizontal FlatList for swiping between multiple photos
    - Close button (X) in top-right corner
    - Page indicator dots at bottom if multiple photos
