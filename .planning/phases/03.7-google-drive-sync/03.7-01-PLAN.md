    **types.ts** - Define all sync-related types:
    ```typescript
    export interface SyncManifest {
      deviceId: string;
      lastSyncedAt: string;
      lastFullBackupId: string | null;
      incrementalIds: string[];
      appVersion: string;
    }

    export interface RemoteBackupEntry {
      id: string;
      type: 'full' | 'incremental';
      filename: string;
      uploadedAt: string;
      sizeBytes: number | null;
    }

    export interface SyncConflict {
      table: string;
      rowId: number;
      field: string;
      localValue: unknown;
      localTimestamp: string;
      remoteValue: unknown;
      remoteTimestamp: string;
    }

    export interface SyncResolution {
      table: string;
      rowId: number;
      field: string;
      resolvedValue: unknown;
      source: 'local' | 'remote';
    }

    export type SyncStatus = 'idle' | 'syncing' | 'error' | 'conflict';
    ```

    **driveAuth.ts** - Google Sign-In wrapper:
    - `signInToGoogle()`: calls hasPlayServices + signIn, returns user info
    - `signOutGoogle()`: calls signOut
    - `ensureDriveAccess()`: calls getTokens(), sets accessToken on CloudStorage.setProviderOptions. On failure, implements retry with clearCachedAccessToken (Android stale token pitfall from research).
    - `addDriveFileScope()`: calls GoogleSignin.addScopes with drive.file for custom folder feature
    - `isSignedIn()`: returns GoogleSignin.getCurrentUser() !== null
    - Configure GoogleSignin with drive.appdata scope and webClientId from env/constant (placeholder for now)

    **driveSync.ts** - Drive file operations via react-native-cloud-storage:
    - `uploadIncremental(filename, localJsonPath)`: reads file content, calls CloudStorage.writeFile to `/backups/{filename}` in AppData scope
    - `uploadFullBackup(filename, localDbPath)`: calls CloudStorage.uploadFile with mimeType 'application/x-sqlite3' to AppData
    - `downloadBackup(remoteFilename, localDestPath)`: calls CloudStorage.downloadFile from AppData
    - `listRemoteBackups()`: downloads sync-manifest.json, parses, returns RemoteBackupEntry[]
    - `uploadSyncManifest(manifest)`: writes JSON stringified SyncManifest to Drive
    - `deleteRemoteFile(remotePath)`: deletes file from AppData
    - All operations wrap with `withDriveAuth()` pattern: call ensureDriveAccess before operation, retry once on 401

    **conflictResolver.ts** - Per-field LWW merge per user decision:
    - `detectConflicts(localChanges, remoteChanges)`: compares field-level timestamps between local change journal entries and remote entries. Returns SyncConflict[] for divergent fields.
    - `autoResolveConflicts(conflicts)`: for each conflict, picks the value with the latest timestamp. Returns SyncResolution[].
    - `applyResolution(resolutions)`: executes SQL updates for each resolved field against the local database.

    **useSyncStore.ts** - Zustand store following usePreferencesStore pattern:
    - State: signedIn (boolean), userEmail (string|null), lastSyncAt (string|null), syncStatus (SyncStatus), pendingConflicts (SyncConflict[]), wifiOnly (boolean, default true), autoResolve (boolean, default false)
    - Actions: setSignedIn, setLastSyncAt, setSyncStatus, setPendingConflicts, setWifiOnly, setAutoResolve, clearSync
    - Persist via AsyncStorage with key 'sync-state'
  </action>
