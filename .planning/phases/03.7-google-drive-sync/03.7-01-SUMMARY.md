## Decisions Made
- Token-first pattern: ensureDriveAccess() called before every Drive operation ensures valid token
- Android stale-token retry: on 401, clear cached access token then re-fetch (avoids common Android pitfall)
- LWW tie-breaking favors local (optimistic local-first architecture per ADR-005)
- Sync store persists via AsyncStorage with key 'sync-state', matching usePreferencesStore pattern
- webClientId configured at runtime (not app.json) since it requires Google Cloud Console project
