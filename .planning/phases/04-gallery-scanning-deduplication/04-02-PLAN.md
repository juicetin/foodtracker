    1. **app.json permissions**: Add `"android.permission.ACCESS_MEDIA_LOCATION"` and `"android.permission.READ_MEDIA_IMAGES"` to the android.permissions array. ACCESS_MEDIA_LOCATION is required for EXIF GPS extraction on Android API 30+.

    2. **galleryScanScheduler.ts** (follows backupScheduler.ts pattern exactly):
       - `GALLERY_SCAN_TASK = 'TASTIMATE_GALLERY_SCAN'`
       - `TaskManager.defineTask(GALLERY_SCAN_TASK, ...)` at module scope:
         - Dynamic import `discoverNewPhotos` from galleryScanService (avoid circular deps)
         - Call `discoverNewPhotos()` -- this is background-safe (no Gemini Nano, just MediaLibrary enumeration + SQLite writes)
         - Return `BackgroundTaskResult.Success` or `.Failed`
         - Do NOT call drainScanQueue here (Gemini Nano is foreground-only)
       - `registerGalleryScan()` -> registers with `minimumInterval: 4 * 60 * 60` (4 hours, conservative for battery)
       - `unregisterGalleryScan()` -> unregisters task
       - `triggerForegroundDrain(onProgress?)` -> async function that:
         - Requests media library permission if not granted
         - Calls `discoverNewPhotos()` first (catch up on any missed photos)
         - Calls `drainScanQueue({ onProgress })` to classify + group + import
         - Returns the drain result stats

    3. **App.tsx**: Add side-effect import `import './src/services/gallery/galleryScanScheduler';` after the backup scheduler import. Add `useEffect` hook that calls `triggerForegroundDrain()` on app foreground (use `AppState.addEventListener('change', ...)` pattern -- when state becomes 'active', drain queue silently in background).

    4. **useGalleryScanStore.ts** (Zustand):
       - State: `isScanning`, `progress: { done: number, total: number } | null`, `lastScanResult: { classified, foodPhotos, mealGroups } | null`, `error: string | null`, `scanEnabled: boolean`
       - Actions:
         - `startManualScan()` -- calls triggerForegroundDrain with progress callback updating store
         - `setScanEnabled(enabled: boolean)` -- toggles background scanning (register/unregister)
         - `reset()` -- clear error and progress

    5. **types/index.ts**: Add `GalleryScan` to `RootStackParamList` navigation type (or `MainTabParamList` if more appropriate -- check existing pattern).

    6. **galleryScanScheduler.test.ts**: Mock TaskManager.defineTask, BackgroundTask, galleryScanService, foodClassifier. Test: task registration, background task calls discoverNewPhotos (not drainScanQueue), foreground drain calls both discover + drain.
