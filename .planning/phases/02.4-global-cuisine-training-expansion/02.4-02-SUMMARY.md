## Decisions Made
- Used checkpoints_v2/best.pt (epoch 16, 76.72%) as best checkpoint -- training continued beyond epoch 9 and improved further
- Docker-based conversion (tensorflow/tensorflow:2.18.0) was necessary because Python 3.14 lacks ai-edge-torch and onnx2tf packages
- Dynamic range INT8 quantization (weights quantized, float32 I/O) matches existing app pipeline -- no preprocessing changes needed
- NHWC layout from onnx2tf conversion: input [1, 224, 224, 3], output [1, 905] -- compatible with app's imagePreprocess
