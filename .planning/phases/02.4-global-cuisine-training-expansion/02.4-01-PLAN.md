Create a merge script at `/home/me/media/foodtracker-ml/scripts/merge_datasets.py` that:

**Step 1: Inventory all datasets**

Scan all dataset directories under `/home/me/media/foodtracker-ml/datasets/` (food101, uec256, cnfood241, khana, thfood50, etc.). For each, enumerate class names and image counts. Build a master inventory:
```python
{
  "food101": {"ramen": 1000, "pizza": 1000, ...},
  "uec256": {"ramen": 122, "udon_noodle": 134, ...},
  "cnfood241": {"ma_po_tofu": 800, ...},
  ...
}
```

**Step 2: Class deduplication**

Build a canonical name mapping. Semantic duplicates are common across datasets:
- Exact matches: `ramen` in Food-101 and UEC-256 (already handled in merged/)
- Name variations: `pad_thai` vs `padthai` vs `pad-thai`
- Language differences: `ma_po_tofu` (English) from different datasets
- Subset relations: a general class containing a specific one (e.g., `curry` vs `green_curry`)

Strategy:
1. Normalize all class names: lowercase, replace hyphens/spaces with underscores, strip leading/trailing whitespace
2. Build exact-match groups first
3. Apply fuzzy matching (Levenshtein distance <= 2 on short names, or substring containment for compound names like `fried_rice`)
4. For ambiguous matches, prefer the more descriptive name as canonical (e.g., `green_curry` over `curry`)
5. Output a JSON mapping: `{ "source_dataset:original_name": "canonical_name" }` plus a reverse mapping showing which sources contribute to each canonical class
6. Log all deduplication decisions for manual review

**DO NOT** merge classes that are genuinely different foods even if names are similar (e.g., `dosa` and `masala_dosa` are different preparations). When in doubt, keep them separate -- it's better to have slightly more classes than to merge unrelated foods.

**Step 3: Create merged_v2 directory**

Target: `/home/me/media/foodtracker-ml/datasets/merged_v2/`

For each canonical class:
1. Create `merged_v2/train/<canonical_name>/` and `merged_v2/test/<canonical_name>/`
2. Symlink all contributing images with source prefix: `f101_0001.jpg`, `uec_0042.jpg`, `cn241_0003.jpg`, `khana_0001.jpg`, etc.
3. Use these prefixes per dataset:
   - food101 -> `f101_`
   - uec256 -> `uec_`
   - cnfood241 -> `cn241_`
   - khana -> `khana_`
   - taiwanese_food_101 -> `tw101_`
   - vietfood67 -> `viet67_`
   - thfood50 -> `thfood_`
   - mafood121 -> `maf_`
   - 30vnfoods -> `vn30_`
   - indonesian_food -> `indo_`
   - indian_foods_hf -> `indhf_`
   - indian_food_images_hf -> `indimg_`
   - ethiopian_foods_hf -> `ethio_`
   - cafd -> `cafd_`
   - padang_food -> `padang_`
   - indian_food_80 -> `ind80_`

**Step 4: Handle class imbalance**

After merging, analyze image counts per class:
- Classes with >1500 images: cap at 1500 by random sampling (to prevent dataset domination by CNFOOD-241's large classes)
- Classes with <20 images: drop entirely (not enough for training). Log dropped classes.
- Log statistics: min, max, median, mean images per class; total classes; total images
