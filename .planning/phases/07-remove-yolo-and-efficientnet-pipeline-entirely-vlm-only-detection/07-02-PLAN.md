    ```typescript
    displayLabel: (item: DetectedItem) => {
      if (item.vlmLabel) return item.vlmLabel;
      if (item.isRefining) return '';  // Empty string signals shimmer state to UI
      return 'Unknown food';  // Fallback if VLM failed and no text input
    }
    ```

    The empty string return for isRefining is intentional -- the UI components (BoundingBoxOverlay, DetectionListItem) will check `item.isRefining` to render ShimmerPlaceholder instead of text. The empty string prevents any flash of text content before shimmer renders.
