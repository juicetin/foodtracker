<objective>
Remove the EfficientNet classification stage and simplify the detection pipeline to bbox-only.

Purpose: The VLM (integrated in Phase 2.6) produces better food identification than EfficientNet. This plan strips the classifier entirely -- model assets, inference code, preprocessing, constants, types, training scripts -- leaving YOLO as a pure bounding-box detector. Every detection becomes a generic "Food Region" that VLM will identify.

Output: Simplified detection pipeline (single-stage bbox-only), 4.9MB APK size reduction, all classification dead code removed.
</objective>
