## Color System Architecture

| Option | Description | Selected |
|--------|-------------|----------|
| Semantic tokens | Intent-based names (background.primary, text.primary) mapped per theme | ✓ |
| Raw hex constants | Centralized hex values but no semantic meaning | |
| CSS variables approach | Web-style custom properties (not native RN) | |

**User's choice:** Semantic tokens (auto-selected, recommended default)
**Notes:** 568+ hardcoded hex values across 20+ files. Semantic tokens prevent future color drift.

## Dark Palette Design

| Option | Description | Selected |
|--------|-------------|----------|
| True dark (Slate) | #0F172A base — AMOLED friendly, warm undertone matching existing grays | ✓ |
| Pure black | #000000 base — maximum AMOLED savings, harsh contrast | |

**User's choice:** True dark Slate (auto-selected, recommended default)
**Notes:** Existing codebase uses Tailwind gray scale which maps naturally to Slate dark palette.

## Migration Strategy

| Option | Description | Selected |
|--------|-------------|----------|
| ThemeProvider + useTheme hook | React context, components pull colors via hook | ✓ |

**User's choice:** ThemeProvider + useTheme hook (auto-selected, recommended default)
